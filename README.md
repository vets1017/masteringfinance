# Open-Source Curriculum / Resources for Mastering Finance

This GitHub repository contains an open-source curriculum and many resources for learning Finance. Inspired by [Hendriyono Rachman's financemasters](https://github.com/hendrirach/financemasters), this curriculum and its many resources aims to help you learn and understand Finance, ranging from beginner, college, to MBA/MF level.

(Don't know where to start? [Click here!](www.google.com))
